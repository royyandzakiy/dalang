# ADR 0002: Name the tool dalang

- **Status:** Accepted
- **Date:** 2026-10-13
- **RFC:** [0002](../rfc/0002-rename-to-dalang.md)

## Context

"cecep" is a Sundanese given name and a pun on "cpp". It is read differently in most languages,
and the tool now generates firmware and Qt projects, not only C++.

## Decision

Rename to **dalang**, the puppeteer of Sundanese and Javanese wayang who brings the puppets to
life. Release under the new name as 2.0.0.

## Alternatives considered

pola, bibit, tunas, cetak, golek, kiln, sprout, scaff, cppinit (reasons in the RFC).

## Consequences

- Keeps the Sundanese identity; pronounced the same in most languages; not tied to C++.
- The GitHub repository has to be renamed; the old URL redirects.
